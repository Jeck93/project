PETUNJUK APLIKASI PWA APP KB

1. TUJUAN APLIKASI
- Aplikasi PWA untuk laporan bulanan PPKBD.
- Menyimpan data di browser (IndexedDB) dan sinkronisasi ke Google Sheets.
- Dilengkapi login aman, form input, tampilan data, dan bantuan pembersihan cache.

2. FILE UTAMA
- index.html : Halaman utama aplikasi.
- login.html : Halaman login pengguna.
- form.html : Form input data KB.
- edit.html : Halaman edit data.
- manifest.json : Konfigurasi PWA.
- service-worker.js : Service worker untuk offline.
- js/ : Semua logika aplikasi berada di folder ini.
- css/ : Styling aplikasi.
- img/ : Asset gambar.

3. KONFIGURASI GOOGLE SHEETS
- js/config.js berisi URL Google Apps Script dan SPREADSHEET_ID.
- Jika spreadsheet diganti, update:
  * GOOGLE_SCRIPT_URL
  * SPREADSHEET_ID
- Gunakan URL Apps Script yang berakhir dengan /exec.

4. KONEKSI DATABASE
- Data lokal disimpan di IndexedDB dengan nama database: LaporanKBDB.
- Koneksi IndexedDB berada di js/db-utils.js dan beberapa file lain seperti js/app.js, js/edit.js, js/sheets-api.js.
- Sinkronisasi remote dilakukan lewat js/sheets-api.js.

5. PENGGUNAAN APLIKASI
- Buka login.html.
- Masukkan username dan password valid.
- Setelah login, halaman utama menampilkan data dan tombol input.
- Gunakan tombol "Input Data Baru" untuk membuka form.
- Isi form dan kirim untuk menyimpan data.

6. PENGUBAHAN SPREADSHEET
- Jika header kolom berubah, edit pemetaan kolom di js/sheets-api.js.
- Jika spreadsheet baru, update ID dan Apps Script di js/config.js.

7. CLEAR CACHE DAN DEBUG
- Untuk membersihkan cache, gunakan file clear-cache.html jika masih ada di root atau debug/ setelah penataan.
- Jika masalah login/netlify identity muncul, bersihkan cache browser atau gunakan hard refresh.

8. CATATAN
- Pastikan service worker dan file PWA terdaftar dengan benar.
- Pastikan localStorage tidak menyimpan token lama saat mengubah konfigurasi login.
- Dokumentasi tambahan bisa ditemukan di file MD yang dipindahkan ke folder archive/.
